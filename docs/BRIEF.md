# Candlewatch — Product Brief

This is the input document for Kiro. Steering docs and specs are generated by Kiro from this brief, not written by
hand, so that `.kiro/` reflects real Kiro usage. Keep this file updated when scope changes.

## 1. One-liner

Candlewatch is a focus timer where a candle is the clock, ghosts are your distractions and abandoned sessions get a
grave.

Tagline: **Keep the candle lit.**
Hackathon: Kiroween 2026, category Costume Contest. Deadline Dec 4, 2026, 2:00 PM PT.

## 2. Who it is for and why it matters

- People who work in timed focus sessions and lose them to one more tab.
- Anyone who finds a plain countdown easy to ignore and a guilty feeling hard to ignore.

The pitch for judges: the Costume Contest asks for a haunting interface whose spooky elements enhance the app's
function. Here every spooky element is a piece of the timer. The candle's height is the time left, the light in the
room is the session's progress, a ghost is a distraction that really happened, and a gravestone is a session that
really died. Take the costume off and nothing is left to read: the costume is the interface.

## 3. Core model

- **Session**: an optional intent (one line of text, such as "write the report"), a length in whole minutes (presets
  15, 25 and 50; custom 5 to 90), a start time, paused spans, and an outcome.
- **States**: `idle` → `lit` ⇄ `paused` → `burned-out` (completed) or `snuffed` (abandoned). No other transitions.
  A paused session may be paused for at most 10 minutes in total; past that it is snuffed.
- **Time**: elapsed time is computed from timestamps (`Date.now()` at start, pause and resume), never by counting
  ticks, so a throttled background tab, a sleeping laptop or a slow frame rate cannot make the timer drift. Ticks only
  redraw.
- **Distraction**: while a session is `lit`, each time the page goes hidden (the Page Visibility API) and comes back
  is one distraction, with its time away. Distractions never change the timer; they only summon ghosts.
- **Break**: after a burned-out session, an optional 5-minute break ("the wax cools"). Skippable.
- **History**: every finished or snuffed session, with its intent, length, outcome, distraction count and time away.
  Stored in localStorage. Lossless JSON round-trip. The current session survives a page reload.

## 4. The costume is the function

Each spooky element shows one piece of state. Nothing is decoration only.

| Element | Shows | Behaviour |
|---|---|---|
| The candle | Time left | Wax height is exactly the fraction of the session left. A drip runs down at each quarter. |
| The flame | Session state | Steady while `lit`; small and blue while `paused`; gutters and sputters in the last minute; smoke when out. |
| The room's light | Progress | The pool of light shrinks with the wax. The room is darkest just before the end. |
| Ghosts | Distractions | One ghost per distraction this session, drifting at the room's edge. Size grows with time away. |
| The graveyard | Snuffed sessions | Each abandoned session leaves a gravestone carved with its intent and date. |
| The shelf | Finished sessions | Each burned-out session leaves a candle stub on a shelf, one shelf per day. |
| The dawn | Completion | When the candle burns out the room fills with early light and a short chime plays. |

The time left is also always shown as text (`12:31`), in the page title while a session runs, and to screen readers.

## 5. Interaction

- **Light**: choose a length, optionally type an intent, press Light (or Enter). Matches strike, the wick catches.
- **Pause**: Space. The flame shrinks and turns blue. Space again resumes.
- **Snuff**: Esc, then confirm. Snuffing is deliberate: the dialog reads "Let it go dark?" with **Keep burning** focused.
- **Graveyard and shelf**: a second view, reached by walking out of the room (a door on the left). Hovering a stone or
  stub shows its intent, length, distractions and time away.
- **Settings**: sound on or off, ghosts on or off (for people who find them too much), default length.
- All of it works with the keyboard alone. Focus is always visible.

## 6. Story and names

- Premise: a lighthouse keeper's last candle. Keep it lit until the watch ends; whatever you leave unwatched comes
  back as a ghost.
- Short, dry flavour text in one strings file, such as "The wick catches.", "Something passed by the window.",
  "The watch is over. Morning.", "Here lies 'write the report', 25 minutes, snuffed at 14."
- No long cutscenes. The first visit shows one line of instructions, then the candle.

## 7. Visual design

- A dark, painterly room lit only by the candle: deep blue-black walls, warm amber light, wax in ivory. Not a retro
  OS, not 1-bit, not a spreadsheet: it must look nothing like the other entries by the same author.
- The scene is SVG and CSS: the candle, the wax drips, the flame (layered radial gradients with a seeded flicker),
  the light pool (a radial mask whose radius follows the wax), the ghosts (translucent shapes with a slow drift).
- One open-licensed display serif and one open-licensed text face, self-hosted.
- Motion is part of the function, so `prefers-reduced-motion` gets a still version: no flicker, no drift, ghosts as
  still silhouettes, every state change still shown by size, colour and text.
- Contrast: the time text meets WCAG AA against the room at every light level, including the darkest minute.
- Sound: a match strike, a soft chime at the end, a breath for the snuff; all generated with Web Audio in code, no
  sound files. Off by default until the first user gesture.
- Responsive: works from a phone in portrait to a wide desktop. No trademarks, logos or real product names anywhere.
  The word "Pomodoro" is a trademark and is never used; say "focus session".

## 8. Technical choices

- TypeScript (strict), Vite, no UI framework. The scene is inline SVG driven by CSS custom properties; the logic is
  DOM-free so it runs in tests.
- One pure session engine: `(state, event, now) → state`. Events: light, pause, resume, snuff, tick, hide, show,
  reload. Rendering reads state; it never owns time.
- Tests: Vitest for unit tests, fast-check for property-based tests, Playwright for end-to-end with a faked clock.
- Hosting: a static site, no backend, no API keys, no AI calls at run time. Free and always on until Jan 29, 2027.
- Node 22+. `npm run dev`, `npm test`, `npm run build`, `npm run e2e`, `npm run verify` (all of them, one command).
- Written from scratch. No code is shared with any other project.

## 9. Non-goals

- Accounts, sync, cloud history, a task manager, to-do lists, statistics dashboards beyond the graveyard and shelf.
- Browser notifications and background push. The page title and the chime are enough.
- A native app or a browser extension. Blocking websites.
- Themes other than the one room.

## 11. Spec plan (in order)

1. `session-engine`: states, transitions, timestamp time math, pause limit, persistence and reload recovery.
2. `distraction-tracking`: visibility events, time away, ghost count; never touching the timer.
3. `candle-scene`: the room, candle, wax, drips, flame states, light pool, dawn.
4. `ghosts-and-graveyard`: ghosts in the room, the graveyard and the shelf, hover details.
5. `controls-and-access`: light, pause, snuff dialog, settings, keyboard, focus, screen-reader text, reduced motion,
   contrast.
6. `sound-and-title`: Web Audio cues, the page title countdown, strings file.
7. `hosting`: static build and free deploy.

## 12. Kiro plan (what to use and why)

- **Steering** (always): `product.md` (what Candlewatch is and is not, the costume-is-function rule), `tech.md`
  (stack, pure engine, time from timestamps, test tools), `structure.md` (folders, naming). Conditional: `scene.md` on
  `src/scene/**` and `**/*.css` (the look, reduced motion, contrast, no trademarks, the screenshot rule).
- **Specs**: the seven above, each with requirements, design and tasks.
- **Hooks**: run Vitest on save for `src/**`; type-check and lint before the agent finishes a task; remind to retake
  screenshots when a file under `src/scene/**` changes.
- **PBT**: time left never increases while `lit`; pausing and resuming any number of times never changes the total
  burn time; elapsed time is the same whatever the tick rate; no event sequence reaches a state outside section 3;
  wax height stays in [0, 1] and never grows during a session; history JSON round-trip is identity; distractions never
  change the time left.
- **MCP**: Playwright MCP with a faked clock to run whole sessions in seconds and capture screenshots of every state.
- **Custom agents**: `costume-reviewer` (read-only; checks every scene change against section 4: each element shows
  state, reduced motion still shows it, contrast holds).
- **Surfaces**: the Kiro IDE for steering, specs and review; the Kiro CLI for running task batches; Kiro Web for a
  pull-request review of the README. Record differences in `KIRO_USAGE.md`.
- **Powers**: install any relevant bundled powers and note what they contributed, or state plainly that none were used.
